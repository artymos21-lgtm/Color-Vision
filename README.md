# ColorVision
Веб-приложение для Android/Chrome: камера или фото -> обработка нескольких цветовых каналов -> OCR цифр.

## Запуск локально
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000

## Деплой
Проект рассчитан на Render через Dockerfile. После публикации откройте HTTPS-ссылку на телефоне и разрешите камеру.

Важно: это вспомогательный инструмент распознавания, не медицинская диагностика.
